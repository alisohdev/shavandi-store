# Asset credits

Photography is downloaded from Unsplash and committed locally as compressed WebP files. It illustrates the F0 collection; it does not represent real inventory. Fixture names and default colors follow the visible garments. Prices, fabrics, fits, care details, and availability are sample content.

The [Unsplash license](https://unsplash.com/license) describes the source's reuse terms. Original image URLs are retained below for provenance. A [weserv image proxy](https://images.weserv.nl/) was used at development time because the image CDN could not be reached directly from this machine. The website makes no requests to either service at runtime.
